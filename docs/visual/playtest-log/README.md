# The playtest log — slice Part B

Three frames from the shipped page, all captured by `npm run test:visual`.

| Frame | What it shows, and what it does NOT |
|---|---|
| `01-title-disclosure.png` | The title screen on a **fresh browser**. The block discloses what the log holds before anything is clicked. "1 moment recorded" is the title-screen arrival itself — nothing else has happened yet. |
| `02-ending-control.png` | The **ending** screen after a full five-battle run, before the copy click. "49 moments recorded, up to the ending (battle 5)" is that run's real count, driven by autoplay — a human's would be far larger, because a human clicks tiles. |
| `03-copied.png` | The same control **after** the click, reporting 7,144 characters on the clipboard. That is one autoplayed run, not a human session. |

**What no frame here shows:** whether a newcomer understands the game. Nothing in this
slice establishes legibility, absolute difficulty or fun. The log is the instrument; the
evidence needs a person.
