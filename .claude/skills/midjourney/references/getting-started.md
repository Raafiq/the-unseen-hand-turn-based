# Getting started — the web app

> Source: Midjourney docs, **Getting Started Guide**
> (`/hc/en-us/articles/33329261836941`). Pasted by the owner **2026-09-01**.
> `[OFFICIAL]`.

The web app at midjourney.com is the main way to use Midjourney. Discord still
works and is optional.

## The loop

1. **Create page** — `midjourney.com/imagine`.
2. **Imagine bar** at the top — type your prompt.
3. Press Enter. Midjourney creates a **set of four images**.
4. At 100% you are done.

Then refine with upscalers, variations, zoom out, pan, or the Editor.

## Settings panel — set defaults once

The settings icon in the Imagine bar sets defaults for **all future prompts**, so
repeated flags do not have to be typed every time. It covers:

Aspect Ratio · Raw · Version · Draft Mode · Stylize · Weird · Variety ·
GPU Speed · Stealth · Video Resolution · Video Batch Size

## Images in prompts

| Use | For |
|---|---|
| Starting Frame | make a video from your image |
| Image Prompts | influence content, composition, style, colours |
| **Style References** | **match the look and feel of another image** |
| Edit Model | create or modify using images plus written instructions |

## Other pages

- **Personalize** — moodboards and personalization profiles.
- **Organize** — download, sort, filter, and folder your creations.
- **Explore** — browse others' work; the Styles tab holds style codes.
